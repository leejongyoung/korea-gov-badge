# 시장형 공기업 후보 공식 CI 조사 (#1)

확인일: **2026-11-18 (KST)**. 기존 [카탈로그](public-enterprises.md)의 시장형 후보 11곳 중 미구현 7곳을 조사했다. 이미 제공 중인 한국전력·한국가스공사·한국수력원자력·한국공항공사 4곳은 이번 재검토 대상이 아니다. 이 분류는 기존 후보 목록 기준이며 현재 공식 공기업 지정 현황을 판정하지 않는다.

## 결과

- 공식 CI 안내 7곳을 확인했고, 원본 파일 4개를 내려받아 실제 파일 구조와 SHA-256을 검사했다.
- 벡터 도형은 부산·인천·여수광양항만공사 **3곳**의 PDF 호환 AI에서 확인했다. 한국지역난방공사 심벌 ZIP의 PDF 표시 영역은 **도형 0개·이미지 1개**였다. PDF나 AI 확장자만 보고 벡터 원본으로 판정하지 않는다.
- 인천국제공항·울산항만공사 안내는 JPG/GIF 다운로드를 제공한다. 강원랜드는 회사 로고 페이지를 확인했지만 이번에 벡터 다운로드 링크를 찾지 못했다. 이는 다른 공식 벡터가 존재하지 않는다는 결론이 아니다.
- **신규 배지 0곳, 기존 4곳 제공 / 7곳 대기 유지**. 해당 CI의 SVG 변환·배지 내장·저장소 및 생성물 재배포에 적용되는 허락을 확정하지 못했다. 이는 이용 금지에 대한 법률 판단이나 기관의 공식 허락 거절을 뜻하지 않는다.
- 원본 파일·페이지 사본은 로컬 검토에만 사용하고 저장소에 올리지 않았다. 기관 문의 메일은 보내지 않았다.

## 기관별 결과

### 한국지역난방공사 (`kdhc`)

[공식 CI 안내](https://www.kdhc.co.kr/kdhc/main/contents.do?menuNo=200129)

공식 심벌 ZIP 안의 심벌.pdf를 열었으나 PDF 표시 영역에는 벡터 도형 0개·이미지 1개가 확인됐다. 다른 CI 다운로드 전체를 검사한 결과는 아니다. CI 페이지의 한난체 상업적 이용 허가 문구는 글꼴에 대한 안내이므로 심벌의 이용조건으로 일반화하지 않는다. 심벌의 SVG 변환·배지 내장·재배포에 적용할 명시적 허락은 확인하지 못했다.

원본 수신: HTTP 200, **113,316 bytes**, 검사 대상 **1개**. 실제 다운로드 URL·SHA-256·파일별 도형/이미지 수는 [검증 메타데이터](market-enterprise-logo-review.json)에 기록했다.

### 인천국제공항공사 (`iia`)

[공식 CI 안내](https://www.airport.kr/co_ko/573/subview.do) · [일반 저작권정책](https://www.airport.kr/ap_ko/1033/subview.do)

### 부산항만공사 (`bpa`)

[공식 CI 안내](https://www.busanpa.com/index.bpa?menuCd=DOM_000000101001004000) · [일반 저작권정책](https://www.busanpa.com/index.bpa?menuCd=DOM_000000108001007000)

공식 AI 파일의 PDF 호환 표시 영역에서 벡터 도형을 확인했다. 일반 저작권정책은 공공누리 표시가 있는 자료의 유형별 이용과 표시 없는 자료의 사전 협의를 안내한다. 해당 CI에 적용되는 공공누리 유형이나 배지 재배포 허락은 확인하지 못했다. 사이트 공통 영역의 공공누리 링크를 CI 파일의 허락 표시로 보지 않았다.

원본 수신: HTTP 200, **156,675 bytes**, 검사 대상 **1개**. 실제 다운로드 URL·SHA-256·파일별 도형/이미지 수는 [검증 메타데이터](market-enterprise-logo-review.json)에 기록했다.

### 강원랜드 (`high1`)

[공식 CI 안내](https://kangwonland.high1.com/kangwonland/contents.do?key=2750) · [일반 저작권정책](https://kangwonland.high1.com/www/contents.do?key=801)

공식 브랜드 체계도는 회사 CI와 하이원리조트 BI를 구분하며, 별도의 강원랜드 로고 페이지를 확인했다. 해당 페이지에서 내려받을 벡터 링크는 찾지 못했다. 일반 저작권 고지는 허용 범위 밖의 복제·배포·변형에 사전 허가를 요구한다. 회사 로고 대신 리조트 브랜드 로고를 넣지 않았다.

[공식 브랜드 체계도](https://kangwonland.high1.com/kangwonland/contents.do?key=2749)에서 회사 CI와 리조트 BI를 구분한다. 기존 후보 slug `high1`을 회사 CI가 검증됐다는 근거로 사용하지 않는다.

## 재개 조건과 검증 한계

기존 저장소에서 받는 출처·이용조건에 맞는 파일별 근거를 확인한 뒤 변환·배지 생성 검증을 진행한다. 공통 푸터의 공공누리 링크나 다운로드 버튼만으로 해당 CI의 이용허락 유형을 단정하지 않는다. 특정 부가 자산(글꼴·캐릭터)의 안내도 회사 심벌 전체에 일반화하지 않는다.

PDF 호환 표시 영역에서 벡터 도형이 확인돼도 최종 배지 적합성·실제 현행 CI와의 일치·변환 품질까지 검증한 것은 아니다. SVG 변환, 시각 비교 및 새 배지 생성은 하지 않았다. 공식 안내·일반 저작권정책을 검토한 결과로서, 파일별 이용허락 확인이 남아 있다.

이슈 [#1](https://github.com/leejongyoung/korea-gov-badge/issues/1)은 열어 둔다. 조사만으로 카탈로그에 배지 미리보기나 사용 가능한 URL을 추가하지 않는다.
