# 대한민국 지방자치단체 배지 카탈로그 (Local Governments)

광역자치단체, 서울 자치구와 시 배지 목록입니다. 기존 광역 17개 항목은 2026년 7월 행정체제 변경을 [이슈 #9](https://github.com/leejongyoung/korea-gov-badge/issues/9)에서 현행화 중입니다.

각 지방자치단체의 공식 심벌마크 및 고유 도시브랜드 규정에 맞추어 독립된 CI 벡터 심벌이 적용됩니다.

## 3. 시 배지 (75곳)

각 시의 시기 SVG를 Wikimedia Commons에서 확인하고 배지용 아이콘으로 가공했다. Commons가 표시한 라이선스는 75건 모두 `Public domain`이다. 원본 URL·SHA-256·가공본 SHA-256은 [출처 목록](city-logo-sources.json)에 남겼다. 시기의 현행 적용 여부는 각 지자체 브랜드 가이드와 대조하는 작업이 남아 있어 [이슈 #8](https://github.com/leejongyoung/korea-gov-badge/issues/8)에서 계속 추적한다.

전남 5개 시의 식별자는 2026년 7월 출범한 전남광주통합특별시 명칭을 반영해 `jeonnam-gwangju-*`로 지정했다. 기존 광역자치단체 표의 광주·전남 항목 정정은 [이슈 #9](https://github.com/leejongyoung/korea-gov-badge/issues/9)에서 추적한다.
